# MU Sports — Frontend

The official sports platform for Mulungushi University. Follow fixtures,
book facilities, track inter-college standings, and register teams.

## The problem

Sports at MU operate through notice boards and WhatsApp groups. There is
no central place to discover fixtures, book courts, or check standings.
MU Sports fixes that.

## Quick start

```bash
# Clone
git clone https://github.com/mu-sports/frontend.git
cd frontend

# Install
npm install

# Configure
cp .env.example .env.local
# Edit .env.local — set NEXT_PUBLIC_API_URL

# Run
npm run dev
